# HuaBook: Структура логів та технічна діагностика Huawei SUN2000

Цей репозиторій містить теоретичну базу, яка детально описує внутрішню логіку роботи та структуру даних інверторів Huawei серії SUN2000. 

Головна мета книги `HuaweiBook.md` — пояснити, **що саме робить проект [Huawei Log Parser](https://andysu3.mooo.com/hua3/) і для чого він створений**.

## Зв'язок із Huawei Log Parser

Файли інверторів Huawei (такі як `.emap` та `.bin`) містять бінарні дані, здамплені безпосередньо з пам'яті процесорів ARM та DSP. Проект [Huawei Log Parser](https://andysu3.mooo.com/hua3/) перетворює цей "зоопарк" закритих форматів у зрозумілий для читання (human-readable) вигляд (CSV/Excel).

Ця книга пояснює:
- Які бувають логи і що в них лежить.
- Як інвертор записує ці дані (механізм FIFO).
- Якими саме Modbus-командами (`0x41`) ці файли можна витягнути з інвертора.
- Як розпарсені дані можна використовувати для прогнозування аварій та аналітики.

## Структура проекту

* `HuaweiBook.md` — Головний файл книги.
* `docs/` — Директорія для автоматичної збірки документації за допомогою Sphinx (містить `conf.py` та `index.md`).
* `preface.md` — Вступне слово та архітектурний аналіз платформи EMAP.
* `3reg.py` та таблиці `.xlsx` — Скрипти та специфікації для роботи з регістрами Modbus.
* `watcher.py` — Скрипт автоматичної компіляції Markdown у HTML/PDF при збереженні змін.

## Збірка документації

Для зручного читання проект може бути зібраний в HTML або PDF за допомогою Sphinx:

1. Переконайтесь, що у вас встановлені залежності з `docs/requirements.txt` (Sphinx, MyST-parser).
2. Ви можете зібрати HTML вручну:
   ```bash
   cd docs
   make html
   ```
3. Або просто запустіть `python3 watcher.py` у фоновому режимі, щоб документація збиралася автоматично при кожній зміні файлу `HuaweiBook.md`.
